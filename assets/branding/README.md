# Homezy Master Brand Assets

This directory contains the master branding assets for Homezy.

- \logo.png\: High-resolution primary brand logo with logomark and wordmark.
- \logo-sm.png\: Compact icon / logomark for app icons, favicons, and notification badges.

### Synced Locations Across Apps:
- Web App (\homezy-website/public/\)
- Admin Console (\homezy-admin-next/public/\)
- Consumer Mobile App (\homezy-consumer/src/assets/\)
- Provider Mobile App (\homezy-provider/src/assets/\)
- Backend Services (\homezy-backend/assets/\)
